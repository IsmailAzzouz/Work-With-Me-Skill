# Agent instructions

## Workflow

- Non-trivial work: follow skill `work-with-me`. Every task gets its own `working-sessions/<Session name>/` folder with a `notes.md`; run the phases in order (knowledge retrieval → scope → acceptance criteria → how → tests → refinements → fixes → coverage/issues).
- Unfamiliar or stale project context: follow skill `learn-project` to create/refresh `agent-journal/`. Read `agent-journal/index.md` before rediscovering the project from scratch.
- Architecture / relationship questions: prefer `graphify` when `graphify-out/` exists (optional).

If your agent does not load skills automatically, read them directly:

- `<skills-dir>/work-with-me/SKILL.md`
- `<skills-dir>/learn-project/SKILL.md`
