First release of Work With Me: two Markdown skills for coding agents.

- **work-with-me** keeps each task's context, scope, acceptance criteria, and verification in a dedicated working session.
- **learn-project** builds a persistent journal of project architecture, conventions, and practical lessons.

The archive includes both skills, supporting references, an agent instructions template, and MIT licenses. Optional companion skills are not included or required.

**Installation:** download and extract `work-with-me-v0.1.0.zip`, then follow the included README to copy both skill folders and connect the workflow to your project instructions.

**Verification:** the `.sha256` asset provides the archive checksum. Agent behavior depends on the host and model; the package does not claim end-to-end compatibility with every agent version.
